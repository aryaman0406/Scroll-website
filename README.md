# OUDH & ROSE — Interactive Scrollytelling Website

A luxury artisanal perfume atelier experience featuring 60fps canvas sequence scrubbing, smooth Lenis inertia momentum, and interactive procedural Web Audio soundscapes.

## 🌐 Live Demo & Deployment

This project is configured for **GitHub Pages**.

### Enabling GitHub Pages on GitHub:
1. Go to your repository on GitHub: **[aryaman0406/Scroll-website](https://github.com/aryaman0406/Scroll-website)**
2. Navigate to **Settings** > **Pages**
3. Under **Build and deployment**:
   - **Source**: Select **GitHub Actions** (recommended, auto-triggered on push) OR **Deploy from a branch** (`main` / `/root`)
4. Once deployed, your site will be live at:
   👉 **https://aryaman0406.github.io/Scroll-website/**

---

## 💻 Local Preview
To preview locally, open `index.html` with a local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node (npx)
npx serve .
```
Then visit `http://localhost:8000` (or `http://localhost:3000`).
